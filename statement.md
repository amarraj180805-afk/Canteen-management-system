# Project Statement

## Project Title
Smart Canteen Management & Demand Analysis System Using Java

## Problem Statement
Managing food orders manually in a college canteen can be time-consuming and may lead to errors in order calculation and billing. This project provides a simple Java-based system to manage student orders, food items, billing, and basic demand analysis.

## Scope of the Project
The project covers the basic management of canteen operations through a console-based Java application.

The scope includes:
- Student login and authentication.
- Admin login and authentication.
- Displaying available food items and prices.
- Selecting food items and entering quantities.
- Validating food quantity and availability.
- Creating orders and calculating bills.
- Providing basic demand analysis for food items.

The project does not include a graphical user interface, online payment system, or database-based storage.

## Target Users
- Students who want to view the canteen menu and place food orders.
- Canteen administrators or staff who need to view menu information and demand analysis.

## High-Level Features
- Student Login
- Admin Login
- Food Menu Display
- Food Selection and Ordering
- Quantity and Availability Validation
- Automatic Bill Calculation
- Demand Analysis
- Console-Based User Interface

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- Visual Studio Code

## Expected Outcome
The system provides a working console-based canteen management application where students can log in, select food items, place orders, and receive a calculated bill. Administrators can log in and view menu and demand analysis information.
